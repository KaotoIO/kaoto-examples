# CSV to XML with camel-dfdl and Kaoto DataMapper

Reads a CSV file with a header line, converts it into XML with named columns using a hand-written DFDL schema (`orders.dfdl.xsd`), then maps that XML to a single invoice (`invoice.xsd`, with a line per CSV row and a grand total) with the Kaoto DataMapper.

See the blog post for the full walkthrough.

## Files

- `orders.csv` - sample input with a header line; a batch order from one customer
- `orders.dfdl.xsd` - DFDL schema; one XML element per CSV column
- `invoice.xsd` - target XML schema for the DataMapper
- `csv-to-xml.camel.yaml` - route that unmarshals the CSV with `camel-dfdl` and transforms it with the DataMapper step
- `kaoto-datamapper-3148ebc4.xsl` - XSLT generated by the Kaoto DataMapper
- `.kaoto` - DataMapper metadata (schemas and XSLT of the step)

## Run

```
camel run orders.dfdl.xsd orders.csv kaoto-datamapper-3148ebc4.xsl csv-to-xml.camel.yaml
```
